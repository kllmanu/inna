# INNA

Indoor navigation is difficult when GPS is unavailable and precise positioning cannot be
assumed. INNA uses WebXR augmented reality to help you record and follow indoor routes
on site: mark a repeatable starting point, capture the corridor one segment at a time,
then use the saved route as an in-place visual guide. Routes are user-recorded; INNA
doesn't infer room locations or guarantee positioning accuracy.

In the Vorarlberg dialect (an Alemannic dialect group spoken in western Austria), the
word "inna" means "inside" or "in".
